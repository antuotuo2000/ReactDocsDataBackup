CORE THESIS · 数据中心占比跃升至 79% × 从 IP 授权到 CoWoS 封装量产的全流程服务

迈威尔定制 AI 芯片与设计服务深度拆解：如何用“IP + 封装 + 云端协同”卡位万亿算力基础设施？

在超大规模云厂商（Hyperscalers）竞相打造专有 AI 训练与推理芯片（XPU）的背景下，迈威尔科技凭借 FY2026 $81.95 亿美元（+42% YoY） 与 Q2 FY2027 单季 $27.39 亿美元（+37% YoY） 的历史性业绩，确立了数据中心核心基础设施的统治地位 FY26 PR ↗ Q2 FY27 8-K ↗。其定制芯片（Custom Silicon）业务并非传统外包代工，而是将云厂商自研计算核心与迈威尔独占的 224G SerDes、Die-to-Die 互连、定制 HBM/SRAM 子系统及 2.5D/3D 先进封装 深度耦合，提供从架构协同到规模量产的全栈交付服务 Portfolio ↗ AWS Collab ↗。

联合架构设计而非单纯后端外包

云厂商保留自研张量计算核，迈威尔注入定制 SRAM、HBM 控制器与片间互连 IP，显著提升每瓦算力与单槽可用内存。

云端优先 EDA 与 <85 天流片服务

依托 AWS 云端分布式算力、分级供电完整性建模与结构化测试网络，大幅压缩 3nm/2nm 超大芯片流片周期。

XPU + 光互连 + 交换机系统级捆绑

每颗定制 XPU 均需配套机架内 224G 铜/光互连、scale-up 交换芯片及机架间 PAM4 DSP，形成单集群多倍芯片价值量。
